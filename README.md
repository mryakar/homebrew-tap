# homebrew-tap

Homebrew formulae of my command-line tools. Tap it once, or install a formula by its full name:

```sh
brew tap mryakar/tap
brew install mryakar/tap/<formula>
```

| Formula | Tool |
|---|---|
| `tib` | [tib](https://github.com/mryakar/tib-cli), a scaffolding CLI for Java services, on Spring Boot or in plain Java |

Each formula is written by the release workflow of its tool when a release is published, in `Formula/<formula>.rb`; do not edit them here.
